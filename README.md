# Results: 

## Study Cases

The following cases evaluate the effects of electrification and demand-side resource integration on distribution transformer sizing.

| Case | Description | Forecast data |
|:---|:---|:---|
| Case 1 | Base load | Electrification growth only |
| Case 2 | Base and EV load | Base with EV adoption |
| Case 3 | Base, EV, and HP load | Case 2 with additional HP |
| Case 4 | Base and EV load with PV | Case 2 with PV generation |
| Case 5 | Base and delayed EV load | Base load and delayed EV |
